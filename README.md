# MoniTune

**Tune your Android display for any external monitor.**

Set the resolution and UI scale you want, keep your MIUI/HyperOS home screen
intact, and force widescreen landscape — on a stock, non-rooted Xiaomi phone,
using a one-time Shizuku grant instead of root.

*MoniTune = moni*tor + *tune*.*

## Why

When you mirror a phone to a monitor, Android picks the resolution, density and
rotation for you, and normal apps may not change them:

- The image is locked to the phone's aspect ratio, with no 1080p/1440p/4K and no
  UI scaling for a big screen.
- **The HyperOS launcher is portrait-only**, so opening the home screen or recents
  while mirroring flips everything back to portrait.
- Changing Android density scatters the MIUI/HyperOS launcher icons across pages.

MoniTune fixes those three things. It is display-only: it does not touch audio.

## Features

- **Resolution** — 720p, 1080p, 1440p, 4K, ultrawide, native, or a custom size.
- **UI scale** — 75% to 200%, with the resulting DPI shown live.
- **Launcher-safe mode** — applies the resolution but leaves density untouched, so
  launcher icons stay put.
- **Force Landscape** — an invisible overlay holds landscape over apps that lock
  portrait, including the HyperOS launcher. Needs "Display over other apps" and
  "Modify system settings"; applied on **Apply Test Profile**, and it needs no
  Shizuku or root.
- **15-second safety revert** unless you tap **Keep Settings**.
- **Auto-apply on connect** — a watcher applies your profile when a monitor
  connects and resets it when it disconnects.
- **Material You appearance** — on Android 12+ the app takes its colours from
  your wallpaper; otherwise pick an accent. Three palette styles, a contrast
  boost, and a themed launcher icon on Android 13+.
- **Check for updates** — tap the version row on the Home screen. Manual only.

## Requirements

- Android 10 or newer.
- [Shizuku](https://shizuku.rikka.app/guide/setup/) (no root) **or** root
  (Magisk/KernelSU). Wallpaper colours need Android 12+; Force Landscape needs
  Android 12+.

## Install

Download `app-release.apk` from the
[Releases](https://github.com/goodeesh/monitune/releases) page and sideload it.
It is not on Google Play: it needs a privileged shell, which a store install
cannot provide. Releases share one signing key, so versions install over each
other.

## How it works

Changing display size, density and rotation needs `WRITE_SECURE_SETTINGS`, a
signature-level permission. MoniTune borrows Shizuku's shell (or root) **once** to
grant it to itself:

```
pm grant com.goodeesh.monitune android.permission.WRITE_SECURE_SETTINGS
```

After that no privileged access is needed, the grant survives reboots, and you
can do the same over ADB by hand. Force Landscape works without any of this.

## Permissions

`WRITE_SECURE_SETTINGS` and the Shizuku API for the one-time setup, plus
`WRITE_SETTINGS`, `SYSTEM_ALERT_WINDOW`, battery-optimization exemption and
notifications for the background parts. `INTERNET` is used only by the manual
update check. The full list with reasons is in [NOTICE.md](NOTICE.md).

## Build from source

```bash
flutter pub get
flutter build apk --release
```

The launcher icon is generated by `tool/generate_icon.py`. Type is bundled in
`assets/fonts` (both OFL), so the app never fetches fonts at runtime.
